## How TrainController Sits

TrainController does not replace the DCC booster, the throttles, or the track you already own. It sits beside them as a named dispatch desk for one job: which digital layout is live, which engine roster still matches the blocks, and what the next person should read before the next train.

If two people share a dispatch PC, each keeps a TrainController style of their own. Extra districts wait for their own title instead of crowding the live occupancy.

A first visit should be one short block check, then the same TrainController desk the next day. That is enough to see if the occupancy holds.

## Traffic Light

| Signal | On the TrainController board | What you do |
|--------|----------------------|-------------|
| Green | Named desk, short live block list | Continue the same dispatch |
| Amber | Two districts mixed in one occupancy | Split the set before you run |
| Red | No title, no note, engines unlabeled | Stop and name the dispatch first |
| Clear | Handoff written, live blocks few | Close TrainController and leave the desk |

## Open Order

1. Open the last TrainController digital layout, not a new empty dispatch desk.
2. Read the engine roster and the last handoff.
3. Finish one visible block inside TrainController.
4. Write what changed, then close with fewer unlabeled engines than you found.
5. If the set feels crowded, drop anything that belongs to a different TrainController district.
6. Confirm TrainController block control still matches the layout you own.

| Home railroad | Personal engines out of the club roster pile |

## After a Week

A week in TrainController is not a larger unlabeled throttle pile. It is the same title, a shorter live block list, and a note that still makes sense before the next session. Take finished trains off the live set so the next visit starts on occupancy that is still open.

Other programs stay where they are. TrainController only keeps the path back: desk name, block control, engine roster, handoff.

## Sign-off

- [ ] The TrainController workspace name is short enough to scan
- [ ] Only live blocks are on the board
- [ ] A second person can read the handoff
- [ ] The last TrainController layout still opens after a restart
- [ ] Finished districts are off the live TrainController set
- [ ] The TrainController summary still matches the engine roster

## Field Note

TrainController is easier to trust when the dispatch desk stays smaller than the throttle pile it came from. Name the session, keep the live occupancy, finish one visible block, and write what changed.
